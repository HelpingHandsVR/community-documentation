# Helping Hands Community Documentation

This repository contains documentation related to the fulfillment of community goals, including rules and guidelines, community management principles, and advice for staff.

The repository has three core branches:

- [`deploy`](https://github.com/HelpingHandsVR/community-documentation/tree/deploy) which contains compiled documentation, handled automatically by GitHub Actions.
- [`source`](https://github.com/HelpingHandsVR/community-documentation/tree/source) which contains the source files for modification and revisions that get compiled into what you see in `deploy`
- [`base`](https://github.com/HelpingHandsVR/community-documentation/tree/base) which is used as a reference point for GitHub Actions on the common ancestor point for the two above branches. It is for modifications to files such as this README, and is intended to be merged into both other branches without conflict.
